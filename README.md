# Simulado-Front-End

Simulados de Desenvolvimento Front-end para Web para estudar para a prova. Abra o `index.html` no navegador.

## Conteúdo

| Simulado | Foco |
|----------|------|
| 1. Fácil | label e for, `<main>`, alt, :hover e ::before, Box Model, querySelector, value e git clone |
| 2. Intermediário | inline-block, value como string, status 404, justify-content x align-items, box-sizing, if/else, branches e validação HTML5 |
| 3. Difícil | flex-grow, media queries mobile-first, preventDefault, localStorage, erro de seletor, links e id, conflito de merge e deploy no GitHub Pages |

Cada simulado tem 8 questões objetivas com 5 alternativas, com correção e explicação na hora, e 2 dissertativas, que o aluno escreve e depois confere marcando os pontos da resposta esperada. As alternativas mudam de ordem a cada tentativa.

As questões cobrem as quatro unidades da disciplina (HTML e fundamentos da Web, CSS e Flexbox, JavaScript e DOM, Git e deploy) e usam como exemplo o site de uma ONG de proteção animal, como no projeto integrador.

## Como usar

1. Baixe o repositório ou o arquivo `index.html`.
2. Abra o arquivo no navegador. Não precisa instalar nada.
