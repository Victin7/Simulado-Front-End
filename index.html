Simulados de Desenvolvimento Front-end

Três simulados por nível de dificuldade para revisar a matéria: 8 questões objetivas com resposta na hora e 2 dissertativas em cada um, que você escreve e depois confere com os pontos esperados. As alternativas mudam de ordem a cada tentativa.

Questões dissertativas

Os exemplos usam o site de uma ONG de proteção animal, como no projeto integrador. Cobrem as quatro unidades: HTML e fundamentos da Web, CSS e Flexbox, JavaScript e DOM, Git e deploy. O gabarito das dissertativas traz os pontos que a resposta precisa ter, não um texto para decorar.
